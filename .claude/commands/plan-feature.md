description: Crea la spec di una feature in docs/features/ e proponi il piano
---

Per la feature "$ARGUMENTS":

1. Leggi docs/PRODUCT.md, docs/DOMAIN.md e il codice rilevante.
2. Copia docs/features/_TEMPLATE.md in docs/features/<slug>.md e compilalo (regole come esempi input → output, modifiche schema, piano a passi, test).
3. Segnala eventuali conflitti con altre feature `doing` in docs/BACKLOG.md.
4. Non scrivere codice: presentami la spec per approvazione.
